# GitHub Pages Uhr

## Dateien
- `index.html` – Konfigurationsseite
- `clock.html` – eigentliche Uhr
- `impressum.html` – Impressum-Seite (Platzhalter)
- `styles.css` – Design
- `app.js` – Logik für Konfiguration, Speicherung und Uhr

## So verwendest du es
1. Lege die Dateien in das Root-Verzeichnis deines GitHub-Pages-Repositories.
2. Aktiviere GitHub Pages für den Branch mit diesen Dateien.
3. Öffne `index.html`, stelle Hintergrund und Uhr ein, und klicke auf **Zur Uhr**.

## Hinweis
Das hochgeladene Hintergrundbild wird im Browser gespeichert (`localStorage`). Für sehr große Bilder kann der Speicher des Browsers zu klein sein.
